# Project Summary
BuilderAI is a full-stack software platform that enables users to create applications by simply describing their requirements in a single prompt. Utilizing AI-powered agents and a Python backend, BuilderAI automates the software development lifecycle—including coding, design, and deployment—allowing users to swiftly transform their ideas into production-ready applications. The platform provides real-time feedback and code generation, significantly enhancing development speed and efficiency.

# Project Module Description
The project consists of several functional modules, including:
- **Hero Section**: Engaging introduction with a prompt input field that triggers application builds, along with guidance for API key configuration and a test connection button.
- **Build Simulation Workspace**: A VS Code-style interface displaying real-time code generation, build status, logs, and application preview.
- **Features Section**: Highlights the platform's capabilities.
- **How It Works**: Explains the three-step process to build software.
- **Showcase Section**: Displays applications built by the community.
- **Pricing Section**: Details subscription plans and features.
- **Settings Modal**: Configuration for API key, model name, and base URL with options to test connections, confirm, or cancel.
- **Footer**: Contains navigation links and contact information.

# File Description Inventory
- **agent.py**: Orchestrates the full build pipeline, connecting the planner, coder, and runner.
- **coder.py**: Generates all project code in a single LLM call and collects generated file contents for the runner.
- **main.py**: FastAPI server handling requests and WebSocket connections.
- **planner.py**: Analyzes user prompts and creates project plans.
- **runner.py**: Executes generated frontend projects locally, installs dependencies with improved reliability, and starts a development server.
- **requirements.txt**: Lists Python dependencies.
- **README.md**: Project overview and instructions.
- **components.json**: Configuration for component usage.
- **eslint.config.js**: ESLint configuration file.
- **index.html**: Main HTML file for the application.
- **package.json**: Project dependencies and scripts.
- **postcss.config.js**: Configuration for PostCSS.
- **public/**: Static assets including favicon and robots.txt.
- **seo-scripts/**: Scripts for SEO-related tasks.
- **site.config.json**: Site configuration settings.
- **src/**: Source files containing components, hooks, styles, and pages.
- **todo.md**: Development plan and guidelines.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Backend**: Python, FastAPI, WebSockets
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **State Management**: React Hooks

# Usage
To set up the project, follow these steps:
1. Install dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```bash
   pnpm run build
   ```
3. Run linting to check for code issues:
   ```bash
   pnpm run lint
   ```
4. Run the backend server:
   ```bash
   cd /workspace/app/backend
   pip install -r requirements.txt
   python main.py
   ```
